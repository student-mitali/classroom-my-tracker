# Classroom My Tracker with Hidden Deadlines **App upgraded:** Google Classroom **Feature:** a "My Tracker" page that finds deadlines hidden in announcements, shows how heavy each week really is, and warns teachers before they pile work onto an already crowded day. **Live demo:** https://student-mitali.github.io/classroom-my-tracker/ > A look-alike prototype built from scratch for the Hack to the Future hackathon. It is not Google's code and is not affiliated with Google. All classes, people, posts and numbers are fictional. ## Problem Classroom's to-do list only shows work that a teacher files under Classwork. Deadlines written in stream announcements or comments never reach it, so students miss them. Because each teacher assigns work on their own, nobody sees when several deadlines land on the same day. This affects every student with more than one teacher, and teachers who unknowingly add to a crunch day. ## Before and after | Classroom today | With this feature | |---|---| | To-do shows only work filed under Classwork | Deadlines found in announcements are surfaced with Add or "Not a deadline" | | No view of total workload | 4-week heatmap of estimated hours, plus a "heavy day" warning | | No help deciding what to do first | "Tonight's plan" with time estimates | | Teachers schedule blind | Teachers see what share of students already have 2+ deadlines that day, with a calmer day suggested | | Dates in announcements stay buried | Teachers are nudged to add announced deadlines to Classwork | Use the **Classroom today / With Hidden Deadlines** toggle at the top of the demo to see both. ## How to run No build step. Open `index.html` in a browser, or open the live demo link above. ## How to try it 1. Open **My Tracker**. Switch between "Classroom today" and "With Hidden Deadlines". 2. Review the "Found in announcements" cards. Add one, dismiss one, or tap "See post". 3. Tick items done and watch the ring, plan and heatmap update. 4. Switch to **Teacher** and open a stream post with a date to see the "Add to Classwork" nudge, then open **Schedule work** and tap bars to test different due dates. ## How it works - **Languages and tools:** plain HTML, CSS and JavaScript in a single file, no libraries. - **Deadline detection:** simple rules in the browser. A post is flagged only if it contains an action word (submit, due, quiz, test, tak, hoga and similar) plus a date, a weekday, or "tomorrow/kal". Posts like "class cancelled on 28 Oct" are ignored. Each result carries a confidence level and needs the student's confirmation. - **Effort estimates:** placeholder values (for example quizzes count as 2 hours). - **Teacher chart:** fictional demo data. Teachers see only aggregated counts, never an individual student's workload. ## Limitations - No real Classroom data or API is used. - Detection is rule-based. A production version would use a language model to read stream posts and attached documents, including mixed English and Hindi text, and would still ask for confirmation. - Time estimates are placeholders, not predictions. ## How Google could roll it out Classroom already holds every class's assignments, announcements and due dates, so the tracker needs no new data. The teacher nudge could ship as a small prompt in the existing assignment screen, using only aggregated counts so that no student's workload is exposed. ## Team - Mitali Devda, devdamitali@gmail.com - Ishaan Gabhale, ishaangabhale@gmail.com
